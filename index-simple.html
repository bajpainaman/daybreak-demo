Every fix becomes a verified detector

Pointed at reth (Paradigm's Ethereum client, ~460k lines). Each fix( commit is a free, maintainer-labeled bug. Daybreak reverts the fix, keeps its test, rebuilds and runs it — settling by compile-and-run whether a test truly guards each bug. No LLM, no fuzzing.

Pillar 3 · verifier-trained models, from scratch, that scale

The verifier is the teacher

A from-scratch model (no pretrained weights) learns to synthesize programs by inverting the exact interpreter — every random program is a free, perfectly-labeled example. Pure RL from reward collapsed (0/10, worse than random); this bootstraps immediately. Every output is checked exhaustively over all 256 inputs.

the honest part

What didn't work

  • Representation isn't the lever. The same anomaly scan localizes bugs no better on IR than on source (6.1% vs 7.0%); library LLVM IR can't even see generic functions. We learned this for ~$3 instead of betting a raise on it.
  • Pure RL from reward collapses from scratch — it never finds the first correct answer to learn from. The fix was to let the verifier generate the data, not just score it.
  • Both results shaped the architecture above. We report the failures because the verifier makes them cheap.
